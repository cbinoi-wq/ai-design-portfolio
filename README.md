# Criss Binoi — AI Design Portfolio

A responsive static portfolio for the AI for Design course. It includes:

- An interactive homepage where every click or tap grows a flower with a varied color and petal shape.
- A project page for the **UNETHICAL** album cover redesign.
- A project page for **The Greenhouse Sanctuary** 3D environment.
- Responsive layouts for wide screens and phones.

## Run locally

From this folder, start any static web server. For example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

The folder is ready for GitHub Pages. Upload the contents to a GitHub repository and publish from the repository's main branch in **Settings → Pages**.
