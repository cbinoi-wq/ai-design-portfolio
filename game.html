Week 2 · What I built

A playable test of the main feeling.

This first draft tests the main loop from my proposal: move, swallow, grow, and make visual noise disappear. The hallucination theme appears through objects that flicker, split into double images, and dissolve without helping the player grow.

The final stage changes the goal. Instead of erasing everything, the player leaves one glowing memory in the quiet city. This tests whether the game can feel satisfying while still ending with a small choice about what deserves to remain.

Questions for playtesters

  1. Was it clear which objects were real and which were hallucinated echoes?
  2. Did moving and swallowing objects feel satisfying?
  3. Did the final protected memory make sense without a long explanation?
